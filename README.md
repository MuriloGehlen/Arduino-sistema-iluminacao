# Sistema de sinalização de iluminação com Arduino

Projeto acadêmico desenvolvido durante o primeiro semestre da graduação,
utilizando Arduino e Tinkercad para estudar lógica de programação,
sensores e automação.

## Sobre o projeto

O projeto consiste em um sistema de sinalização de iluminação utilizando
um fotorresistor (LDR) e um LED RGB. A leitura do sensor determina a
indicação visual correspondente ao nível de iluminação do ambiente.

O sistema também possui botões para alterar seu estado de funcionamento
e um display de 7 segmentos utilizado na montagem final.

## Funcionamento

O sistema possui diferentes estados de operação:

- **Normal:** a cor do LED RGB é determinada pela leitura do LDR.
- **Alerta:** o LED permanece vermelho.
- **Desligado:** o LED permanece desligado.

Os botões são utilizados para alternar entre os estados do sistema.

## Componentes

- Arduino
- Protoboard
- Fotorresistor (LDR)
- LED RGB
- Resistores
- Botões
- Display de 7 segmentos
